# Four main data tpes in python (primitive) 
- Booleans (the value mus be true or false) 
- Integers (`whole numbers` 1,2,545.... NOT 3.14) 
- Floats (a decimal number, eg. 3.14, 4.0, 5.5.....) 
- String (text eg. "My Name is Bill") 

## Variables 
A **variable** is like a container that holds information/data. 
It is a name given for a location in memory.
